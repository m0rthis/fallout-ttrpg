# Icon attribution — game-icons.net (CC BY 3.0)

Every creature token in `assets/tokens/` and every item tile in `assets/icons/` is generated
by `scripts/build-tokens.mjs` from an icon published on **[game-icons.net](https://game-icons.net/)**.
The generator recolours the original artwork onto a Pip-Boy-styled field; the underlying
shapes are unmodified. Source SVGs are vendored in this repository under `packs-src/icons/`.
